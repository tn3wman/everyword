Use it in your application

One engine, several ways to capture content. The browser bundle is built and served by this workspace.

Your app owns the translation database

Choose the database in your app's config. Everyword prepares its own tables, checks the connection, saves generated translations, and invalidates them when the model or content changes. Your app keeps database access and credentials. Browser storage is an optional copy.

node bin/everyword.js init /path/to/app --storage sqlite
node bin/everyword.js doctor --project /path/to/app
node bin/everyword.js serve --project /path/to/app

# Use your existing PostgreSQL database instead:
node bin/everyword.js init /path/to/app --storage postgres \
  --database-env EVERYWORD_DATABASE_URL
# Inject the connection variable using Infisical, then:
infisical run -- node bin/everyword.js cache migrate --project /path/to/app

Initialization generates an app integration and reports where native UI or asset text needs an adapter. It preserves your existing files. No manually approved translation database is required.

Web & Electron renderers

Mount the wrapper on an owned document. It watches later DOM changes and keeps original text for language switching.

import {createEngine, httpProvider, wrapDOM,
        cachedProvider, browserCache}
  from 'everyword';

const endpoint = 'http://127.0.0.1:4317';
const {revision} = await fetch(endpoint + '/api/status')
  .then(response => response.json());
const engine = createEngine({
  sourceLocale: 'en',
  provider: cachedProvider(httpProvider({
    endpoint: endpoint + '/api/translate'
  }), {storage: browserCache({storage: null}), version: revision})
});

const app = wrapDOM(document, {engine, locale: 'es'});
await app.ready;
await app.setLocale('ja');
app.disconnect();

Native UI & structured content

For native apps, your host exposes a capture/apply bridge. For email and notification payloads, translate owned text fields.

const localized = await translateObject(payload, {
  engine, locale: 'ar'
});

const app = wrapAdapter({
  capture: () => host.captureOriginalText(),
  apply: (results, state) =>
    host.applyText(results, state),
  restore: () => host.restoreText()
}, {engine, locale: 'ar'});

await app.refresh();

The wrapper keeps only the latest locale request and the host retains source strings for reset. SwiftUI, Compose, canvas text, images, and closed shadow roots need their own capture strategy.

Run local machine translation

npm run setup downloads the quality model once. Install llama-server from llama.cpp first. Initialize your app's database before starting the service. The default Hy-MT2-7B Q8 model runs locally without an account or subscription. Your configured database stores generated translations automatically. You can also point the server at a compatible model endpoint.

npm run setup
node bin/everyword.js init
npm start

# Smaller CPU-friendly engine:
npm run setup -- --fast
npm start -- --engine fast

# Optional compatible model endpoint:
npm start -- --model your-local-model \
  --model-url http://127.0.0.1:11434/v1

For another web origin, add --allow-origin https://your-app.example. Keep credentials on the server. Public deployments still need authentication and rate limits at the service boundary.
